# 12维阅读模板

分析前先了解当前库的 `Templates/文献笔记模板.md`。保留用户现有12维名称及要求；下表是自包含的备用规范，适用于新会话找不到模板时。理论论文、综述、质性研究不强套实验结构；不适用处说明原因。

| 维度 | 应回答的问题 |
|---|---|
| 1. 基本信息 | 原文标题、中文暂译、作者、年份、期刊、卷页、DOI、研究类型与时间；主题词是原列还是AI归纳 |
| 2. 研究背景 | 学术／实践问题，已有认识与作者所称不足；为什么采用此场景 |
| 3. 研究问题 | 作者明确提出什么，哪些是AI归纳；问题与可得证据是否匹配 |
| 4. 理论基础 | 核心概念如何定义、如何落到变量或材料；机制是被检验还是仅作解释 |
| 5. 数据来源 | 来源、时间、样本流程、分析单位、数量、纳入排除、缺失、代表性和获取条件 |
| 6. 研究方法 | 方法承担的作用、比较／对照、识别假设、分析流程、稳健性；解释给入门读者 |
| 7. 技术实现 | 工具、版本、模型、参数、提示、处理流程、代码／补充材料与复现缺口；明确是否实际运行 |
| 8. 主要发现 | 全部原文图表及中文解释、关键数值、效应与不确定性、支持范围、冲突信息 |
| 9. 创新贡献 | 作者主张、自己的评价及依据分开；未系统检索不自封首创 |
| 10. 研究局限 | 作者承认与AI评议分开；数据、测量、设计、统计、解释和外推问题及后果 |
| 11. 可借鉴之处 | 可复现或迁移的具体做法、条件和调整；与本人方向及已有文献的有据联系 |
| 12. 延伸思考 | 候选问题、来源、拟用数据与设计、困难、检索词、验证状态；不能把作者已提出方向冒充新空白 |

方法和结果的中文表格应足够完整，包含有助复核的样本、单位、分母、比较基准和证据位置；正文详细解释，不只罗列术语。精度沿用原文，不补造缺失值。

## 原文图表清单

逐页盘点，并区分真正图表与正文引用。可使用如下列：

| 原编号 | PDF页序／印刷页码 | 多面板／跨页 | 图片文件 | 中文解释位置 | 已视觉核对 |
|---|---|---|---|---|---|

没有图或表时据实说明；不能为了模板补造。跨页表按顺序附齐，全部图表应同时有清晰原图、来源编号和说明。复制、裁切属于来源提取，不是新生成的研究图。

## Markdown结构

正式入库优先沿用当前库frontmatter，常见字段：文献ID、标题、作者、年份、期刊、DOI、主题、研究方法、数据来源、阅读状态、来源文件、分析日期、tags。

正文依次为：标题和核心判断；知识关联；证据标记；12维分析；个人阅读记录；入库／更新记录。个人阅读记录含理解、疑问、判断、想尝试的工作和后续行动，保持本人填写。

预览不分配正式ID，不写“已入库”；保持可复用的完整文件和图表，便于用户确认后转换路径与补充元数据，无需从头重读重建。

默认预览成品位于 `D:\文献阅读预览\本篇子目录\阅读预览.md`，原图表放在同一子目录下的 `figures/` 等资源目录。Markdown图片用相对路径，对话中的交付链接用实际绝对路径；本篇目录应完整可迁移，不能依赖C盘临时图片。
